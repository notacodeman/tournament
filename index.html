Run a tournament for any game with a timer: standings, brackets, a picking wheel and a race timer for the stream. There's a preset for Parking Garage Rally Circuit.

  1. Download a template CSV for a spreadsheet, JSON for code

    It has an example tournament with every kind of row: settings, the tracks and classes that count, players, times and bracket results.

  2. Fill it in

    Open the CSV in Excel or Google Sheets, replace the example rows, and save it as CSV again. The row_type column says what each row is; rows starting with # are notes and get skipped.

  3. Drop the file here

    The tournament opens with standings, a bracket, the picking wheel and the timer. It's saved in this browser and listed on the right for next time.

  4. Go live optional

    Share it under a short code. Viewers get a watch page that updates by itself; tick a box to make a second code that lets helpers add times and bracket results.

  5. Change it and upload again

    Edit on the page, or use Download file to get it back as CSV or JSON. Uploading a file with the same id replaces that tournament.
