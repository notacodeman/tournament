Run a tournament for any game with a timer: standings, brackets, a picking wheel and a race timer for the stream. There's a preset for Parking Garage Rally Circuit.

  1. Create a tournament

    The guide on the right walks you through it: the game, which tracks and classes count, how it's scored, and who's playing. No spreadsheet needed.

  2. Run it on the page

    Add times as people race, build a bracket, spin the picking wheel for the next track, and keep the race timer on screen or pop it out.

  3. Go live optional

    Share it under a short code. Viewers get a page that updates by itself; tick a box for a second code that lets helpers add times and bracket results.

  4. Keep a copy

    Tournaments are saved in your browser. Live ones are removed from the site a week after their last change, so use Download file to keep one, and drop the file here to bring it back.

A viewer code opens the watch page. A participant code lets you add times and results.
